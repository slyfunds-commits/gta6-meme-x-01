## About the meme

The joke turns the thirteen-year wait for GTA VI into a loading screen frozen at 99%, with an oversized make.fun ghost holding a star coin as if keeping the wait alive. `main.ts` copies the post-address placeholder from `POST.json`; `render.py` draws the scene, and `meme.png` is the finished image.
